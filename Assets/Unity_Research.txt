    Scriptable Objects vs Prefabs:
    I am still confused about this, but the basics seem to be that a scriptable object is a data container 
    that can be used to store and manage data in a more flexible way than prefabs. Scriptable objects can 
    be used to create reusable data assets that can be shared across multiple game objects, while prefabs 
    are more focused on creating reusable game object templates. Scriptable objects are often used for things 
    like game settings, character stats, and other data that needs to be accessed and modified at runtime, 
    while prefabs are used for creating instances of game objects with specific components and properties.
